# STM32 与 ROS 停车职责（当前实现）

STM32 负责底层执行兜底，ROS 负责导航停车。原本地碰撞模块已删除，不再需要 STM32 配置运动学矩阵、轮径、安装内缩、制动距离或释放滞回。

| 条件 | 当前行为 |
|---|---|
| ROS 显式急停 `0x100: 03 FF 00 00 00 00 00 00` | 优先全车停车，清除缓存和待执行命令 |
| 有效 ROS 通信中断超过 500 ms | 电机任务停车，心跳任务仍上报原故障事件 |
| 真实严重电机故障（现有故障位判定） | 停车并禁止运动，状态任务仍上报原故障事件 |
| 运动提交/实际发送失败、原生负应答或确认超时 | 终态失败、停车、取消后续运动；失败运动不重试 |
| 参数错误、同步缓存不完整、队列中运动命令超过 500 ms | 拒绝并保留负 ACK/执行失败统计，不额外广播停车 |
| 已运行速度停止更新，ROS 心跳仍正常 | STM32 不再自行停车，由 ROS 监测命令源超时并停车 |
| 测距近障碍、无回波、测距错误、反馈陈旧、位置参考不足 | 不再作 STM32 导航停车决策，由 ROS 判断 |

失联/故障停车统一由 `motor_safety_poll()` 每 10 ms 检查，状态和心跳任务只报告事件。持续相同条件不重复广播；停车提交失败保留待处理标志。恢复通信或故障解除不会重放已取消运动。

`sync=0` 按队列顺序逐条提交，无四轮收集窗口。`sync=1` 仍缓存到驱动器，完整四轮准备后才允许实体按钮/05触发。正常心跳时可等待按钮数秒；停车清空缓存。初始按钮事件 result=0 仅表示请求接受，后续失败仍返回同序号 ACK=1、事件 result=2。

CAN 仍为 500 kbit/s，默认物理地址1～4；现有协议 ID 和字段不变。默认 WAIT_ACK：实际发送后收到匹配地址/功能的原生02才成功；同步广播匹配地址映射第一项（默认1）的 FF 02。显式无应答模式只确认发送完成。ACK不是到位证明，内部 HAL_BUSY 等待不提前生成负ACK。其他地址/功能、旧9F不确认当前命令。

测距采集及0x110/0x111上报保留。距离为原始毫米值，不扣安装内缩；无效为FFFF、VALID清零。普通无回波不置EMERGENCY，多数时间无回波不能直接禁止普通导航；有效距离仍须参与ROS制动/绕行。编号：0前、1左、2右、3/4机械臂两侧、5后。

## 修改文件

- `Core/Src/motor_control.c`、`Core/Inc/motor_control.h`：删除本地导航校验、运行租期、四轮收集；保留终态关联、内部诊断和必要停车。
- `Core/Src/main.c`：统一停车归属，移除测距到电机保护的调用，继续采集/上报。
- `Core/Inc/chassis_safety_config.h`：仅保留通信/请求超时和测距采集参数。
- `Core/Inc/can_protocol.h`、`Core/Src/can_protocol.c`：更新注释；不开放绕过结果关联的原始运动透传。
- 删除 `Core/Src/chassis_collision.c`、`Core/Inc/chassis_collision.h` 和专用运动学测试/配置；更新 `CMakeLists.txt`、`tools/run_host_tests.py` 及受影响的固件测试。
- 保留工作区已有的 `can_transport` / `zdt_can_driver` 异步结果关联修改。

## 验证与复测

`python tools/run_host_tests.py`：28组C场景、32项Python检查通过，覆盖单轮即时执行、无运行租期、校验拒绝不停车、失联/故障停车、原生失败/超时停车、按钮缓存、急停优先、测距上报。

普通 Debug 固件构建通过（诊断模式关闭）：`build/ros-stop-policy/STM32_Motor_Controller.elf`，同目录有hex/bin。Flash 62564 B，RAM 33280 B。未烧录、未实机验证。

架空复测：

1. 100 ms心跳，逐轮sync=0、±5 RPM，核对转动/原生确认；仅保持心跳超过500 ms，确认不因速度停发自主停车，再由ROS发零速/急停。
2. 保持心跳缓存四轮sync=1，数秒后按实体按钮，检查同序号事件、终态ACK、FF 02；缺一轮仅拒绝启动，不额外广播停车。
3. 分别停发所有有效ROS通信超过500 ms、发显式急停、模拟运动负应答/丢确认，确认FE 98 00 6B、后续运动清除、恢复后不重放。故障位用驱动允许的安全模拟方式验证，不制造机械堵转。
4. 确认无遮挡/近距离时0x110/0x111均工作；STM32不因距离停车；ROS对有效距离制动/绕行，并在速度输入断流但心跳继续时主动停车。

ROS端修改要求见 [可复制提示词](ROS_停车职责对齐提示词.md)。
